# Documentación Oficial del Proyecto PRISMA (Backend)

Este directorio contiene los documentos oficiales aprobados para la entrega académica y técnica de la plataforma PRISMA (Motor Backend Web & API REST):

1. **[Documento de Arquitectura PRISMA.pdf](./Documento%20de%20Arquitectura%20PRISMA.pdf)**:
   - Especificación de arquitectura general de software en capas.
   - Modelo C4 (Contexto, Contenedores, Componentes).
   - Diagrama de Despliegue con pipeline CI/CD en GitHub Actions hacia Render y Vercel.
   - Seguridad sin estado con JWT HMAC-SHA512 y roles RBAC.
   - Esquema relacional de persistencia PostgreSQL (16 tablas normalizadas en 3FN).

2. **[Documento de Requerimientos PRISMA.pdf](./Documento%20de%20Requerimientos%20PRISMA.pdf)**:
   - Catálogo formal de Requerimientos Funcionales (RF-01 a RF-06).
   - Matriz de Atributos de Calidad y Requerimientos No Funcionales (ISO/IEC 25010).
   - Reglas de negocio del modelo mayorista B2B (split payment, PIN de entrega antifraude).
   - Catálogo de excepciones E2E y flujos alternos.

3. **[Informe Final Proyecto PRISMA IEEE.pdf](./Informe%20Final%20Proyecto%20PRISMA%20IEEE.pdf)**:
   - Informe formal de culminación de proyecto bajo el estándar de publicación IEEE.
